# Pacman Game

## Descripción

Este repositorio contiene una versión modificada del juego Pacman desarrollado con Python y FreeGames.

## Cambios realizados

- Se mejoró el comportamiento de los fantasmas para que tomaran decisiones más inteligentes durante la persecución.
- Se modificó el diseño del tablero para ofrecer una experiencia de juego diferente.
- Se aumentó la velocidad de los fantasmas para incrementar la dificultad de la partida.
